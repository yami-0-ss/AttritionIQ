# AttritionIQ – HR Analytics Dashboard 📊

## 📌 Project Overview
AttritionIQ is an HR Analytics Dashboard designed to help understand employee attrition and workforce trends. It presents HR data in an interactive format, making it easier to explore employee-related insights and support data-driven decisions.

## 🎯 Objectives
- Analyze employee attrition and workforce patterns.
- Explore factors that may be associated with employee turnover.
- Present HR insights through an interactive dashboard.
- Make workforce data easier to understand.

## 🛠️ Technologies Used
- **Python** – Data processing and application development.
- **Pandas** – Data manipulation and analysis.
- **SQL** – Querying and retrieving data.
- **Snowflake** – Cloud data storage and management.
- **Streamlit** – Building the interactive web application.
- **VS Code** – Writing and managing project code.

## ✨ Key Features
- Interactive HR analytics dashboard.
- Employee attrition and workforce trend analysis.
- Visual presentation of HR insights.
- Exploration of potential attrition risk factors.
- Online access through Streamlit Community Cloud.

## 🔄 Project Workflow
1. Stored and managed HR data using Snowflake.
2. Retrieved and processed data for analysis.
3. Used Python and Pandas to prepare and analyze the data.
4. Developed an interactive dashboard using Streamlit.
5. Deployed the application online for easy access.
